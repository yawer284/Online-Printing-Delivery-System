# Online Printing & Delivery System

## Project Overview
The **Online Printing & Delivery System** is a comprehensive digital platform designed to automate and streamline the printing process. It allows customers to upload documents, customize print settings, receive dynamic real-time pricing, and track their delivery. Additionally, it provides print shop operators with a robust dashboard to manage orders and assign delivery agents efficiently.

This repository contains the complete software engineering documentation, encompassing both the **System Analysis & Design** and **Database Design** phases.
